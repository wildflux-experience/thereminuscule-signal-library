# Signal : `bathy-plancha-saint-brandon`

This signal presents the route followed by the *Plancha* Autonomous Surface Vehicle (ASV), along with its attitude and the seafloor depth recorded during a survey in Saint-Brandon, Mauritius, in November 2022. The depth data were collected using an ETC 400 single-beam echosounder, allowing the underwater terrain to be mapped along the vehicle GPS position.

*Source: Ifremer - https://doi.org/10.5281/zenodo.11408548*
