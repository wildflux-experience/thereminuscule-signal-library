# Signal : `bathy-plancha-boucan`

This signal presents the route followed by the *Plancha* Autonomous Surface Vehicle (ASV), along with its attitude and the seafloor depth recorded during a survey in Boucan, Réunion, in September 2023. The depth data were collected using an ETC 400 single-beam echosounder, allowing the underwater terrain to be mapped along the vehicle GPS position.

*Source: Ifremer | dataset: https://doi.org/10.5281/zenodo.11409792 | article: https://doi.org/10.1038/s41597-024-04267-z*
