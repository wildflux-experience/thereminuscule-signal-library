# Signal : `bathy-plancha-passe-dubois`

This signal presents the route followed by the *Plancha* Autonomous Surface Vehicle (ASV), along with its attitude and the seafloor depth recorded during a survey in the Passe Dubois, Aldabra, Seychelles, in Octobre 2022. The depth data were collected using an ETC 400 single-beam echosounder, allowing the underwater terrain to be mapped along the vehicle GPS position.

*Source: Ifremer | dataset: https://doi.org/10.5281/zenodo.12706292 | article: https://doi.org/10.1038/s41597-024-04267-z*
