# Signal : `turtle-iot-048`

Dive profile data recorded from a juvenile green sea turtle (*Chelonia mydas*) swimming off the coast Saint-Gilles, Réunion Island.

The turtle was tagged on 2022-01-06 using an *IoT Turtle Tracker* device.

The recording spans approximately 22 days.

*Source: Ifremer DOI / LIRMM (CNRS – University of Montpellier) – 2021*
