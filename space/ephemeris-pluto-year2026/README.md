# Signal : `ephemeris-pluto-year2026`

Ephemeris data for Pluto as seen from the center of Earth for the year 2026.

Ephemeris data are a time-by-time description of a space object in the sky: they tell us where it appears, how far away it is, how bright it looks and how it moves.

*Source: NASA JPL Horizons (https://ssd.jpl.nasa.gov/horizons/)*
